# 角色素材接收规格

> 这份文档定义了 **你提供什么 → 我能接入什么**。三个梯度（A 入门 / B 进阶 / C 专业），从最简单到最完整，按你能拿到的素材选一档即可。
>
> 当前项目角色用的是临时 SVG 占位（不好看，可以替换）。任何一档完成后都能立即替换。

---

## 梯度速览

| 梯度 | 你提供什么 | 能展示什么 | 你的工作量 | 我的接入工作量 |
|------|------------|------------|------------|--------------|
| **A. 单张立绘**（最低门槛） | 1 张透明 PNG | 静态展示 + 呼吸/滑入动画 | 极低（5 分钟） | 5 分钟 |
| **B. 表情集**（推荐） | 4–6 张透明 PNG，每张一个表情 | 不同提醒切换不同表情 + 反馈情绪 | 中（1–2 小时） | 30 分钟 |
| **C. Live2D 模型**（远期） | 完整 Live2D 文件夹/zip | 眨眼、口型、骨骼物理动作 | 高（需 Cubism Editor / 委托美术） | 1 天（含渲染管线接入） |

> 不推荐：**GIF / 序列帧** 在透明背景下兼容性差、文件大，跳过。

## A 档 · 单张立绘（最低门槛）

### 规格
| 项 | 要求 |
|----|------|
| 格式 | **PNG**（必须透明背景，alpha 通道） |
| 尺寸 | **建议 600×800**（宽×高 = 3:4 比例），上下限 400×533 到 1024×1365 都行 |
| 比例 | 必须竖向（3:4 或 2:3）。横向图会被压扁 |
| 内容 | **只画正面**，全身（含脚）或半身均可，全身更好 |
| 边距 | 上下左右留 20–40px 透明边（防贴边） |
| 背景 | **必须完全透明**（白底不行，会变成白色矩形） |
| 命名 | `idle.png` |

### 怎么做（如果你没现成的）
1. **AI 生图**（推荐）：Midjourney / NovelAI / Stable Diffusion 生成，提示词加 `transparent background, full body, white background`（白底便于后续抠图）
2. **抠图**：用 [remove.bg](https://remove.bg)（免费、一键）或 PS「魔棒+反选+羽化」
3. **检查**：在 Photoshop / Figma 里放在深色背景上看看边缘有没有白边

### 你交付什么
1 个文件：`idle.png`

### 我接入什么
- 替换当前 SVG 组件
- 自动套用呼吸 + 上下浮动动画
- 保留滑入/淡出出场动画
- 5 分钟搞定

## B 档 · 表情集（推荐 ⭐）

### 规格
A 档所有规格 +：

### 表情清单（按重要性排序，最少 1 张，理想 4 张，完整 7 张）

| 文件名 | 用途 | 何时显示 | 必须 |
|--------|------|----------|------|
| `idle.png` | 平时表情 | 默认状态、其他表情没准备时的兜底 | ✅ 必须 |
| `happy.png` | 开心 | 用户点「搞定 ✓」时（积极反馈） | ⭐ 强烈推荐 |
| `thirsty.png` | 渴了 / 想喝水 | 喝水提醒 | 推荐 |
| `hungry.png` | 饿了 / 想吃饭 | 吃饭提醒 | 推荐 |
| `sleepy.png` | 困了 / 想睡觉 | 睡觉提醒 | 推荐 |
| `tired.png` | 累了 / 久坐 | 久坐起身提醒 | 可选 |
| `eye_strain.png` | 眼疲劳 | 护眼休息提醒 | 可选 |

### 一致性要求（重要）
- **同一角色、同一镜头距离、同一构图位置**（不要一张半身一张全身）
- **同尺寸**（推荐都是 600×800）
- **同朝向**（都是正面，或都是 3/4 侧脸）
- 不同的只是 **表情和小动作**（眼神、嘴型、手势）

### 你交付什么
一个文件夹，里面放 1–7 张 PNG：
```
your-character/
├── idle.png        必须
├── happy.png       强烈推荐
├── thirsty.png
├── hungry.png
├── sleepy.png
├── tired.png
└── eye_strain.png
```
**只交 `idle.png` 也能跑**，其他没提供的会自动用 idle 兜底。

### 我接入什么
- 建立 **提醒类型 → 表情图** 映射表
- 喝水提醒弹出时显示 `thirsty.png`，按"搞定"切到 `happy.png` 再离场
- 30 分钟搞定

## C 档 · Live2D 模型（远期，阶段 4）

### 规格
标准 Live2D Cubism 模型完整目录，入口为 `*.model3.json`。

### 文件清单（典型 Live2D 模型）
```
your-character/
├── character.model3.json        # 必须，入口清单
├── character.moc3               # 必须，模型核心数据
├── character.physics3.json      # 推荐，物理（头发/裙摆摆动）
├── character.cdi3.json          # 可选，显示信息
├── textures/
│   └── texture_00.png           # 必须，贴图
├── motions/
│   ├── idle.motion3.json        # 待机动作
│   └── tap.motion3.json         # 点击反应
└── expressions/
    ├── happy.exp3.json
    └── sleepy.exp3.json
```

### 大小限制
- 单文件 ≤ 50 MB
- 总大小 ≤ 200 MB
- 贴图建议 ≤ 2048×2048

### 你交付什么
整个文件夹 zip 起来，或者直接给一个 `*.model3.json` 入口文件 + 它引用的所有同目录文件。

### 我接入什么
- 接入 PixiJS + pixi-live2d-display + Cubism Core 渲染管线
- 模型导入 UI（设置面板选 zip → 解压 → 注册）
- 表情/动作切换 IPC
- 这部分是 [`docs/FEATURES.md`](FEATURES.md) 里的 8.x + 9.x，工作量 1 天起

### 来源建议
- 自己用 **Live2D Cubism Editor** 制作（官方有免费版）
- 委托 Live2D 美术（B 站 / 闲鱼 / Skeb 上有人接单，价格 500–5000+）
- 部分模型作者会公开免费模型（须注意授权）

## 你需要做的决定

| 选项 | 适合你如果你 | 推荐 |
|------|-------------|------|
| 走 A 档 | 想最快看到效果，先用着 | 起步快 |
| 走 B 档 | 想做出像样的桌宠，不同提醒有不同情绪 | ⭐ 我推荐这个 |
| 走 C 档 | 想做"真桌宠"产品，未来想公开发布 | 远期目标 |

**最佳路径**：A → B → C 渐进。先 A 档 1 张图占位（淘汰当前丑 SVG），后面有空再加表情升到 B 档，最后真要做产品时上 C 档。

## 提交位置

你把素材准备好后，放到：
```
D:\project\ai_code\desktop_pet\role\
```
按梯度建子目录：
- A 档：`role/idle.png`
- B 档：`role/<角色名>/idle.png` + 其他表情
- C 档：`role/<角色名>/`（整个 Live2D 目录）

放好后告诉我目录路径，我直接接入。

## 常见问题

**Q：我只会用 AI 生图，画不了那么多表情怎么办？**
A：A 档（1 张图）就行，先跑起来。表情可以后续慢慢补。

**Q：背景透明怎么搞？**
A：[remove.bg](https://remove.bg) 拖进去 5 秒下载，一张免费，多张要花点钱。或者让 AI 出图时就要求"transparent background"。

**Q：图片大小有限制吗？**
A：单张 PNG 建议 ≤ 2 MB（视觉无损），上限 5 MB。

**Q：可以用 JPG 吗？**
A：**不行**，JPG 没透明通道，会显示成白色矩形（就是我们今天遇到的问题）。

**Q：角色一定要正面吗？**
A：是的，桌宠用户 99% 时间看到的是正面。三视图（背/侧/正）只在 C 档 Live2D 里需要给美术建模参考，运行时只显示正面。

**Q：尺寸非要 600×800 吗？**
A：不严格，但**必须是竖向**。横向图会被强行拉伸变形。
