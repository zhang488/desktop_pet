# Desktop Pet 功能文档

> 桌面宠物式定时提醒应用 —— 角色到点出场提醒（喝水/久坐/吃饭/睡觉等），响应后隐藏退出。
>
> 技术栈：Tauri 2 + Rust + React 19 + TypeScript + (规划中) Live2D Cubism + PixiJS
> 目标平台：Windows + macOS
> 文档维护：本文件是功能总览与进度看板，新增/完成功能时同步更新状态标记。

## 9. 模型管理与导入（用户自定义角色）

> 让用户从设置页手动导入第三方角色模型。强依赖第 8 节（Live2D 渲染管线）完成后再开发。
>
> **背景调研**：市面桌宠类应用普遍支持的模型格式 ——
> - **Live2D Cubism**（最主流）：文件夹形式，入口为 `*.model3.json`，含 `.moc3` / `.physics3.json` / `textures/*.png` / `.motion3.json` 等
> - **VRM**（3D，VTuber 生态）：单文件 `.vrm`（基于 glTF 2.0）
> - **Spine**：`*.json` + `*.atlas` + `*.png` 组合
> - **PNG 序列帧 / GIF**：简陋桌宠
>
> 第一期只做 Live2D（与 8.x 渲染栈匹配），其他格式按需扩展。
